# 雙人關係合盤 v1

固定配對參考古籍《三命通會》卷二：
https://zh.wikisource.org/zh-hant/三命通會/卷二
https://ctext.org/wiki.pl?if=gb&res=532360

採既有八字計算 UTC+8 / 立春 / 節令 / 00:00 換日。十神引用同版本 lunar-typescript 1.8.6 的 SHI_SHEN 表，分別以甲方及乙方日主為中心，不反轉。五行生循環木火土金水，剋循環木土水火金。

五合：甲己、乙庚、丙辛、丁壬、戊癸。
六合：子丑、寅亥、卯戌、辰酉、巳申、午未。
六沖：子午、丑未、寅申、卯酉、辰戌、巳亥。

每人四柱跨比較，共16個有向位置，交換人物後矩陣轉置；計數不去掉重複符號，因為不同柱位是不同配對。計數僅供核對，不轉為評分。日支另顯示為傳統夫妻宮比較，不將非伴侶關係推定成夫妻。

目前版本只做八字，不混用紫微演算法或推測前世。相處題目為本 App 編寫的一般討論提示；不是對個人性格或關係結果的預測。固定符號規則的單元測試不等於命理有效性的科學驗證。

兩人需不同ID（同生日不同人物可比較），不要求性別組合。選擇與結果僅在本頁，不變更目前人物、備份或個人歷史，也不呼叫AI。
