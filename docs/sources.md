## I Ching

Each fair coin is 2 (reverse) or 3 (obverse). Three-coin sum 6/7/8/9 maps to old yin/young yang/young yin/old yang. First toss is the bottom line. Six-bit representation is bottom-to-top, lower trigram first. Moving values 6 and 9 flip their bit. Table lookup determines both original and changed King Wen numbers. Cryptographic random bytes use parity (256 divisible by 2), giving unbiased fair bits; no Math.random. Coin outcomes are 1/8,3/8,3/8,1/8. Diagram reverses display only, never data order.

## Bazi

Normalized UTC+8 date-time is passed to lunar-typescript. Year and month use exact Li Chun/Jie time; default EightChar sect 2 retains current day at 23:00, day changes 00:00. Hour follows the package's late-zi convention, documented and tested. Engine API also tests sect 1. Yun sect 1 uses the package solar-term interval computation, direction by year stem yin/yang and traditional binary gender. We never hard-code starting age. Annual year is located at July 1 inside the post-Li-Chun cycle; relations only explicit pairwise tables. No useful-god inference.

## Zi Wei

The common calendar resolves inputs before iztro. BySolar receives 0 for early zi, 1–11 for other double-hours, 12 for late zi. Config sets full-book default algorithm, lunar year boundary, lunar nominal-age boundary, fixed default mutagen table, selectable day/leap rule. Fourteen main stars and auxiliary/malefic stars are generated by iztro. Decadal/yearly projections are copied into JSON while config is active, not later lazily recomputed. See accuracy.md for exact settings and source limitations.

## Current AI provider

DeepSeek Responses API, pinned endpoint https://api.deepseek.com, configurable model default deepseek-flash. Uses the OpenAI-compatible SDK with JSON Schema and reasoning disabled. Response status must be completed; Zod schema and fact references are independently checked. Official compatibility source: https://api-docs.deepseek.com/guides/responses_api/ . This replaces the original OpenAI provider; original SDK naming is retained for compatibility.
